# 🧠 Neural Genesis

> *"The beginning of an artificial mind."*

Selamat datang di **Neural Genesis** Repositori ini adalah *sandbox* dan jurnal pribadi saya dalam bereksperimen, meracik algoritma, dan mempelajari **Machine Learning** dari titik nol. 
Setiap baris kode di sini ialah langkah awal  untuk memahami bagaimana sebuah mesin bisa belajar, beradaptasi, dan mengenali pola dari sebuah data.

## 🎯 Objectives
- Membedah dan memahami konsep inti algoritma Machine Learning.
- Membangun fondasi yang kuat dalam manipulasi data dan logika pemrograman.
- Melatih model ML pertama untuk melakukan prediksi data secara akurat.

## 🛠️ Tech Arsenal
- **Core:** Python
- **Data Manipulation:** NumPy, Pandas
- **Machine Learning Engine:** Scikit-Learn
